## Demythologizing the Legend

This repository contains the source materials for this submission to 
the Journal of Visualization and Interaction.

The main text source is `./index.qmd`, which also contains most of the
R code for the figures.  A copy of just the R code has been extracted into
`./index.R`.  The data for the correlation matrix figures is in 
`./trade-years.csv`.

The `./Diagrams/` and `./Pinker/` directories contain
additional code for generating diagrams.
